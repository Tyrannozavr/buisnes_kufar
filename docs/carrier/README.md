# ТЗ_Перевозчик (20.07) — оценка и статус

**Оригинал:** [`dev/+ТЗ_Перевозчик_20.07/`](../../dev/+ТЗ_Перевозчик_20.07/)  
**Дата оценки:** 20.07.2026  
**Статус:** ✅ **согласовано** — **65 000 ₽**, срок **~2 месяца**  
**Оплата:** получено **10 000 ₽** (2026-08-12), остаток **55 000 ₽** — [payment-and-schedule.md](payment-and-schedule.md)

**Не путать** с [../tz15/](../tz15/) — там закрытый пакет **ТЗ_15 = 70 000 ₽** (роли, контрагенты, каркас перевозчика/MVP).  
Это ТЗ — **полноценный контур** транспорта / поиска / заявок / перевозок поверх того каркаса.

---

## Сравнение с ТЗ_15

| | ТЗ_15 | ТЗ_Перевозчик |
|--|-------|----------------|
| Характер | «вширь»: роли, меню, таблицы, диалоги | «вглубь»: матчинг, заявки, двусторонние перевозки |
| Что уже в коде | многое закрыто | меню + простой CRUD ТС/водителей + заглушки Заявки/Перевозки/поиск компаний |
| Трудозатраты (ориентир) | **1.0** | **≈ 1.1–1.3** |

Итого: по объёму работ **не меньше ТЗ_15, скорее чуть больше / плотнее**.

---

## Предложенная вилка (формат как у ТЗ_15 → 40 / 60 / 75)

| Вариант | Сумма | Срок | Режим |
|---------|-------|------|--------|
| **1** | **45 000 ₽** | ~полгода | Фоном, без жёсткого дедлайна, без полной шлифовки всего сайта |
| **2** | **70 000 ₽** | ~2 месяца | Нормальный темп + другие задачи; scope ТЗ без договора перевозки |
| **3** | **90 000 ₽** | ~1 месяц | Приоритет; весь scope + финальная ручная шлифовка (регресс / стабильность) |

Логика относительно прошлой вилки 40/60/75: здесь ступени выше, потому что scope плотнее (маркетплейс заявок + перевозки), а не «чуть допилить MVP».
