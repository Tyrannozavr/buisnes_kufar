# Ручная приёмка ТЗ_Перевозчик — пошаговый чек-лист

**Ветка:** `feature/carrier-tz`  
**UI:** http://localhost:8088 (dev nginx; при другом `DEV_NGINX_PORT` — свой URL)  
**Пароль везде:** `123456`

| Роль | Email |
|------|-------|
| Клиент (продавец) | `seller@gmail.com` |
| Перевозчик | `carrier@gmail.com` |
| Экспедитор | `forwarder@gmail.com` |

**Как читать:** каждый пункт — «куда нажать» → «что должно произойти».

Seed:

```bash
docker compose -f docker-compose.dev.yml exec backend poetry run python scripts/ensure_schet_test_users.py
```

---

## §A — ЛК «Транспорт»

1. Войти `carrier@gmail.com` → **Транспорт**
2. Заполнить карточку: Откуда/Куда (через запятую города/регионы), грузоподъёмность, объём, марка, госномер ТС/п/п, габариты, дата погрузки, тип кузова, способы загрузки, ADR, при необходимости догруз
3. Сохранить → ТС в списке с ключевыми полями
4. Редактировать → сохранить → F5 — данные на месте
5. Удалить → подтверждение → ТС исчезает
6. Навести на «?» у Откуда/Куда — видна подсказка

- [ ] CRUD полной карточки
- [ ] Справочники тип кузова / загрузка / ADR
- [ ] Confirm delete + подсказки

---

## §B — ЛК «Водители»

1. `carrier@gmail.com` → **Водители**
2. Добавить ФИО, телефон, ВУ, **ИНН**
3. Редактировать / удалить

- [ ] ИНН сохраняется

---

## §C — Поиск транспорта

1. Войти `seller@gmail.com` → меню **Поиск транспорта**
2. Задать фильтры (Откуда/Куда, тип кузова и т.д.) → **Найти транспорт**
3. Снизу — карточки ТС; баннер про отправку заявок
4. **Показать контакты** — тип+название, ИНН, адрес, телефон, email; кнопки «Отправить заявку» / «Написать сообщение»
5. **Добавить в избранное**
6. **Отправить заявку** — активирует пассивную заявку у перевозчика

- [ ] Матчинг ТС (не компаний)
- [ ] Автозаявки + активный отклик

---

## §D — Заявки перевозчика

1. `carrier@gmail.com` → **Заявки**
2. Видны заявки от поиска; активная — подсвечена и выше
3. Контакты клиента / избранное / **Принять заявку**
4. После принятия — toast со ссылкой на **Перевозки**; клиент в контрагентах; сообщение в чат

- [ ] Лента + highlight
- [ ] Accept → перевозки + контрагенты + чат

---

## §E — Перевозки клиента

1. `seller@gmail.com` → **Перевозки**
2. Строка с номером `0000N`, датой, перевозчиком
3. Колонка договора — заглушка «Позже»
4. **Данные о грузе** — редактирование (~25 полей)
5. **Данные транспорта** — только просмотр
6. **К заказу клиента** — привязка к активному заказу Продаж (1:1)

- [ ] Таблица + груз edit + 1:1 заказ

---

## §F — Перевозки перевозчика

1. `carrier@gmail.com` → **Перевозки**
2. Зеркало: клиент вместо перевозчика
3. Груз — просмотр; транспорт — выбор ТС и водителя из базы

- [ ] Edit транспорта из флота

## §G — Избранное

1. Клиент: **Избранное** — сохранённые ТС (карточки)
2. Перевозчик: **Избранное** — сохранённые заявки

## API smoke (curl)

После логина получить cookie/token как обычно, либо через pytest ASGI.

```bash
# словари
curl -s http://localhost:8015/api/v1/company/fleet-dictionaries | head

# поиск (нужен Authorization)
curl -s -X POST http://localhost:8015/api/v1/transport/search \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"body_types":["Тентованный"],"from_locations":[{"name":"Москва"}]}'
```
