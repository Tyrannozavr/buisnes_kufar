## §A — ЛК «Транспорт» (перевозчик)

### A1. Открыть список

1. Войти: `carrier@gmail.com` / `123456`
2. Открыть ЛК → пункт меню **Транспорт** (URL: `/profile/transport`)
3. Проверить: заголовок «Транспорт», кнопка **Добавить ТС**, сразу под ними список; в списке есть **Volvo FH · А123ВС 77**
4. Проверить в карточке строки: тип кузова, тоннаж/объём, маршрут Москва → …, статус «активен»

- [x] Список ТС и seed-машина видны

### A2. Добавить новое ТС

1. Нажать **Добавить ТС** → открылась модалка формы
2. В форме заполнить:
  - **Откуда:** `Москва`
  - **Куда:** `Нижний Новгород`
  - **Название / марка:** `Газель Next`
  - **Госномер:** `В456ОР 77`
  - **Тип кузова:** выбрать из списка (например «Фургон»)
  - **Грузоподъёмность:** `1.5`
  - **Объём:** `12`
  - **Дата загрузки:** сегодня
  - **Способы загрузки:** выбрать хотя бы один (список широкий, текст читаемый)
3. Нажать **Добавить**
4. Проверить: модалка закрылась; toast «ТС добавлено»; в списке появилась **Газель Next · В456ОР 77**

- [x] Создание ТС работает

### A3. Редактировать

1. Кликнуть по строке «Газель Next» (не по кнопкам) → открылась модалка с деталями ТС
2. Вверху модалки нажать **Редактировать** → открылась форма редактирования
3. Изменить объём на `14`, нажать **Сохранить**
4. Обновить страницу (F5)
5. Проверить: у «Газель Next» объём **14 м³**

- [x] Редактирование сохраняется после F5

### A4. Выключить / удалить

1. Переключить toggle у «Газель Next» → статус «неактивен» (серый)
2. Нажать **Удалить** → в confirm согласиться
3. Проверить: строка исчезла; toast «ТС удалено»
4. **Не удалять** seed **Volvo FH** — нужен для §C–§F

- [x] Confirm delete и выключение работают

### A5. Подсказки Откуда/Куда

1. Навести на «?» у полей **Откуда** и **Куда** в форме
2. Проверить: видны пояснения про город / регион / страну

- [x] Подсказки на месте

3. Проверить таблицу: колонки Заказ / Дата / Контрагент / Договор / Груз / Транспорт / К заказу клиента
