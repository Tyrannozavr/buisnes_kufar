## A. ЛК «Транспорт» (Перевозчик)

- Список ТС перевозчика; добавить / редактировать / удалить (с подтверждением).
- Поля карточки: Откуда, Куда (город и/или регионы; у «Куда» ещё страна), грузоподъёмность, объём кузова, марка, гос. номер т/с, гос. номер п/п, габариты п/п (Д×Ш×В), дата погрузки, тип кузова (1 из справочника), способ загрузки (несколько), ADR (несколько), догруз + вес/объём догруза.
- Подсказки «?» у Откуда/Куда.
- Справочники: `Тип кузова.txt`, `Способ загрузки.txt`, `Опасные грузы.txt`.

**Сейчас:** упрощённый CRUD (`company_vehicles`: name, plate, type, tons, m³, notes).

---

## B. ЛК «Водители» (Перевозчик)

- Список; добавить / редактировать / удалить.
- Поля: ФИО, контактный телефон, вод. удостоверение, ИНН.

**Сейчас:** CRUD без ИНН.

---

## C. Главное меню «Поиск транспорта»

- Форма фильтров (те же оси, что у ТС + вес/объём груза при догрузе).
- «Найти транспорт»:
  1. Результаты снизу (карточки ТС).
  2. Автосоздание заявок в ЛК «Заявки» у соответствующих перевозчиков (1 ТС → 1 заявка у владельца; несколько ТС одного перевозчика → одна заявка на перевозчика?).
- Карточка: «Показать контакты», «Добавить в избранное», «Отправить заявку».
- Контакты: тип+название, ИНН, юр. адрес, телефон, email; кнопки «Отправить заявку», «Написать сообщение».
- «Отправить заявку» при уже созданной пассивной заявке — поднять/подсветить у перевозчика.

**Сейчас:** поиск компаний-перевозчиков по строке (`transport-search.vue`), не матчинг ТС.

---

## D. ЛК «Заявки» (Перевозчик)

- Автопополнение из поиска; сортировка по дате ↓; хранение **14 суток**, затем автоудаление.
- Активный отклик («Отправить заявку» клиентом) — выделить и поднять в дате.
- Команды: контакты клиента, избранное, «Принять заявку».
- При принятии: запись в «Перевозки» у обеих сторон; клиент ↔ контрагенты / перевозчики; сообщение в чат клиенту.

**Сейчас:** заглушка `shipment-requests.vue`.

---

## E. ЛК «Перевозки» (Производитель / Продавец)

- Таблица как Продажи/Закупки: Заказ | Дата | Перевозчик | Договор перевозки | Данные о грузе | Данные транспорта | К заказу клиента.
- Нумерация заявки `00000`, ежегодно сбрасывать.
- «Данные о грузе» — диалог (~25 полей), редактирует только клиент; перевозчик — просмотр.
- «Данные транспорта» — только просмотр.
- «К заказу клиента» — выбор активного заказа из Продаж; связь **1:1**.
- Договор перевозки — **вне этого ТЗ** («позже»).

**Сейчас:** заглушка `shipments.vue`.

---

## F. ЛК «Перевозки» (Перевозчик)

- Зеркало таблицы: Заказ | Дата | Клиент | Договор | Данные о грузе | Данные транспорта.
- Данные о грузе — просмотр.
- Данные транспорта — редактирование: марка/госномер из базы ТС, п/п авто, водитель из базы + ВУ/телефон авто; по умолчанию ТС из результата поиска.

**Сейчас:** заглушка.

---

## G. Избранное

- Клиент: избранный транспорт (как в результатах поиска, без «Добавить в избранное»).
- Перевозчик: избранные заявки.

**Сейчас:** заглушка `shipment-favorites.vue`.

## Вне scope
