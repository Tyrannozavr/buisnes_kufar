# Бланк: Договор перевозки грузов

**id:** `carriage_contract`  
**Семья:** А (Заказчик ↔ Перевозчик)  
**Тип:** нестрогий, как договор поставки  
**Образец логики:** `2_Страница_Договор перевозки.docx`  
**Клон:** договор поставки; красный шрифт = что переименовать.

Макет: шапка → преамбула (юрлицо / ИП) → `ТЕКСТ ДОГОВОРА` (шаблон) → подписи Заказчик / Перевозчик.

---

## Поля

| id | На бланке | Цвет | Править на А4 | Откуда |
|----|-----------|------|---------------|--------|
| `number` | ДОГОВОР ПЕРЕВОЗКИ ГРУЗОВ № ___ | жёлтый | да | `system.number` (после генерации можно поправить) |
| `city` | г. ГОРОД | жёлтый | да | `company.city` Заказчика |
| `date` | «___» _________ 20___ г. | жёлтый | да | `system.date` |
| `customer.full_name` | ПОЛНОЕ НАЗВАНИЕ ОРГАНИЗАЦИИ (Заказчик) | жёлтый | да | `company.lk` Заказчика: ОПФ + название |
| `customer.role_label` | «Заказчик» | красный шрифт | нет (статика роли) | отличие от «Поставщик» |
| `customer.official.position` | ДОЛЖНОСТЬ | жёлтый | да | `company.officials` |
| `customer.official.name` | ФИО | жёлтый | да | `company.officials` |
| `customer.foundation.kind` | ДОКУМЕНТ ОСНОВАНИЯ | жёлтый | да | `company.lk` (устав / доверенность) |
| `customer.foundation.title` | НАЗВАНИЕ ДОКУМЕНТА | жёлтый | да | `company.lk` |
| `customer.ogrn` | № ОГРН | жёлтый | да | `company.lk`, **только если Заказчик ИП** |
| `carrier.full_name` | ПОЛНОЕ НАЗВАНИЕ (Перевозчик) | жёлтый | да | `company.lk` перевозчика из «Перевозчики» |
| `carrier.role_label` | «Перевозчик» | красный шрифт | нет | отличие от «Покупатель» |
| `carrier.official.position` | ДОЛЖНОСТЬ | жёлтый | да | `company.officials` перевозчика |
| `carrier.official.name` | ФИО | жёлтый | да | `company.officials` |
| `carrier.foundation.kind` | ДОКУМЕНТ ОСНОВАНИЯ | жёлтый | да | `company.lk` |
| `carrier.foundation.title` | НАЗВАНИЕ ДОКУМЕНТА | жёлтый | да | `company.lk` |
| `preamble_formula` | какая строка преамбулы | — | нет | `company.type` каждой стороны: юрлицо или ИП |
| `body` | ТЕКСТ ДОГОВОРА | шаблон | через редактор шаблонов | `template.body` |
| `sign.customer` | подпись Заказчик / ФИО / дата / М.П. | жёлтый ФИО | ФИО да | `company.officials` |
| `sign.carrier` | подпись Перевозчик / ФИО / дата / М.П. | жёлтый ФИО | ФИО да | `company.officials` |

Реквизиты банка на макете страницы 2 не разведены отдельной таблицей (только подписи). По аналогии с поставкой — те же галки «Реквизиты Заказчика / Перевозчика», поля жёлтые из `company.lk`.

---

## Преамбула (что подставить, не логика диалогов)

**Юрлицо:**  
`{full_name}, далее — «Заказчик|Перевозчик», от имени которого действует {position} {fio}, действующего(ей) на основании {foundation} {foundation_title}`

**ИП:**  
`{full_name}, далее — «Заказчик|Перевозчик», зарегистрированный в реестре индивидуальных предпринимателей под № {ogrn}`

Прочие сочетания ТЗ опускает — пользователь правит жёлтые поля сам.

Шаблон: кнопки «Таблица» и «СпецСим2» выключить (типовой договор).
