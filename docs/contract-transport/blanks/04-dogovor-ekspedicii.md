# Бланк: Договор транспортной экспедиции

**id:** `expedition_contract`  
**Семья:** Б (Клиент ↔ Экспедитор)  
**Тип:** нестрогий, как договор поставки  
**Образец логики:** `5_Страница_Договор экспедиции.docx`

Сейчас в коде только запись `transport_contract`. Этот файл — про **полный бланк**.

Макет: шапка → преамбула → `ТЕКСТ ДОГОВОРА` → реквизиты Клиент / Экспедитор → подписи.

---

## Поля

| id | На бланке | Цвет | Править на А4 | Откуда |
|----|-----------|------|---------------|--------|
| `number` | ДОГОВОР ТРАНСПОРТНОЙ ЭКСПЕДИЦИИ № ___ | жёлтый | да | `system.number` |
| `city` | г. ГОРОД | жёлтый | да | `company.city` Клиента |
| `date` | «___» _________ 20___ г. | жёлтый | да | `system.date` |
| `client.full_name` | ПОЛНОЕ НАЗВАНИЕ (Клиент) | жёлтый | да | `company.lk` нанимателя (поставщик или покупатель) |
| `client.role_label` | «Клиент» | красный шрифт | нет | не «Заказчик» и не «Поставщик» |
| `client.official.*` / `foundation.*` / `ogrn` | как в договоре перевозки | жёлтый | да | `company.lk` / officials; ОГРН если ИП |
| `forwarder.full_name` | ПОЛНОЕ НАЗВАНИЕ (Экспедитор) | жёлтый | да | `company.lk` организации из «Перевозчики» |
| `forwarder.role_label` | «Экспедитор» | красный шрифт | нет | |
| `forwarder.official.*` / `foundation.*` | как у перевозчика в бланке 1 | жёлтый | да | `company.lk` экспедитора |
| `preamble_formula` | юрлицо / ИП | — | нет | `company.type` |
| `body` | ТЕКСТ ДОГОВОРА | шаблон | редактор шаблонов | `template.body` |
| `req.client.*` | тип, название, адрес, ИНН, КПП, р/с, банк, корр, БИК | жёлтый | да | `company.lk` Клиента |
| `req.forwarder.*` | то же справа | жёлтый | да | `company.lk` Экспедитора |
| `sign.client` / `sign.forwarder` | должность, ФИО, подпись | жёлтый | ФИО да | `company.officials` |

На макете страницы 5 реквизиты есть сразу (не только подписи).

Четыре роли сделки (для понимания сторон, не поля бланка): Поставщик, Покупатель, Экспедитор, Перевозчик. На этом бланке только **Клиент** и **Экспедитор**.
