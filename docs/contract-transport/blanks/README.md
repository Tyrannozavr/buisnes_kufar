## Легенда цвета (с бланка, печать ч/б)

Из `ТЗ_Расширение` + этот пакет:

| В docx | На бланке | Смысл |
|--------|-----------|--------|
| Чёрный текст | `static` | Не поле. Не заполняется. |
| **Жёлтая заливка** | `yellow` | Автозаполнение, **можно править на бланке**. |
| **Красная заливка** | `red` | Автозаполнение, **на бланке не править**. |
| **Серая заливка** | `gray_block` | Целый блок (`ТАБЛИЦА`, `ДОПОЛНИТЕЛЬНЫЕ УСЛОВИЯ`), не набор по буквам на А4. |
| Красный **шрифт** | `diff_from_supply` | Не про редактирование. Отличие от договора поставки (роли, название). |

Строгие бланки (5–7): вёрстка заморожена. Поля — только через диалог «Редактировать данные…», не кликом по А4.

## Откуда вообще берутся данные

| Код источника | Где в системе |
|---------------|----------------|
| `system.number` | Генерация номера документа |
| `system.date` | Дата создания документа |
| `parent.number` / `parent.date` | Рамочный договор, к которому приложение |
| `company.lk` | ЛК «Данные компании» стороны |
| `company.type` | Юрлицо / ИП → формула преамбулы |
| `company.city` | Поле «Город» ЛК Заказчика |
| `company.officials` | Должностные лица ЛК |
| `company.fill_addresses` | «Данные заполнения» → адреса приёма груза |
| `shipment.cargo` | «Данные о грузе» заказа на перевозку (`CargoData`) |
| `shipment.transport` | «Данные транспорта» (`transport_snapshot`) |
| `order.lines` | Позиции заказа Продаж (кол-во × вес карточки, сумма) |
| `template.body` | Текст из редактора шаблонов |
| `user.dialog` | Только ручной ввод в диалоге (пустые текстовые поля ТЗ) |
| `counterparties` | Список контрагентов + поставщик |

Пробел к текущему коду: в ТЗ у водителя **паспорт РФ**; в ЛК водителя есть ФИО, телефон, ВУ, ИНН — паспорта нет.
