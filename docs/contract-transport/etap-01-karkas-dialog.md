## §1.2. Модели и API ⏳

Семь типов, нумерации, родитель, привязка к сделке и к организации из «Перевозчики».

| Задача | Детали |
|--------|--------|
| Типы | `carriage_contract`, `carriage_application`, `carriage_order`, `expedition_contract`, `forwarder_assignment`, `forwarder_receipt`, `warehouse_receipt` |
| Родитель | заявка → договор перевозки; поручение/расписки → договор экспедиции |
| Номера | рамочные — своя серия; заявка — 1, 2, 3… внутри родителя; договор-заявка — `000001` |
| Список для пикера | договоры перевозки / экспедиции по выбранной организации-перевозчику |
