## Как проверить — подробный сценарий (UI)

### Подготовка

1. Dev-стек уже должен быть поднят.
2. В терминале:
   ```bash
   docker compose -f docker-compose.dev.yml exec backend poetry run python scripts/ensure_schet_test_users.py
   ```
3. Открой в браузере: **http://localhost:3014** (frontend)  
   (если у тебя nginx на 8080 — тот же логин через него).

### Вход

1. Открой **http://localhost:3014/auth/login**
2. Email: **`seller@gmail.com`**
3. Пароль: **`123456`**
4. Нажми войти.

### Куда кликать

1. В шапке / меню профиля открой **«Продажи»**  
   URL примерно: **http://localhost:3014/profile/sales** (или «Продажи» в ЛК).
2. Убедись, что открыта закладка **«Товары»** (не «Услуги»).
3. Найди любую строку заказа (например заказ **00001**).
4. В колонке **«Договор перевозки»** нажми синюю ссылку **«Создать док. перевозки»** (не путать с «Создать документ» в соседних колонках).

### §1.3 — диалог типов

5. Должно открыться окно **«Выберите тип документа»** с **семью** радиокнопками:
   - Договор на перевозку грузов  
   - Заявка к договору на перевозку грузов  
   - Договор-заявка  
   - Договор транспортной экспедиции  
   - Поручение экспедитору  
   - Экспедиторская расписка  
   - Складская расписка  
6. Кнопки: **Создать** / **Отмена**.

#### Сценарий A — договор перевозки (рамочный)

7. Выбери **«Договор на перевозку грузов»** → **Создать**.
8. Откроется окно выбора: слева организации из **«Перевозчики»**.
9. В списке должна быть **ООО Перевозчик Тест** (из seed).
10. Выбери её → справа появится список договоров (должен быть **№ 999**).
11. Нажми **«Выбор»** (или **«Создать новый»** если хочешь новый номер).
12. Вернись в таблицу Продажи — в ячейке **«Договор перевозки»** у этой строки одна ссылка вида:  
    **«Договор перевозки № 999 от … · ООО «Перевозчик Тест»»** (договор и перевозчик не двумя кнопками).

#### Сценарий B — заявка без договора на заказе

13. Возьми **другую** строку заказа, где в колонке перевозки ещё пусто (или только «Создать документ»).
14. **Создать док. перевозки** → радио **«Заявка к договору…»** → **Создать**.
15. Должно всплыть сообщение:  
    **«В заказе нет выбранных Договоров на перевозку грузов»** → **Понятно** → обратно к выбору типа.

#### Сценарий C — заявка при уже привязанном договоре

16. На строке, куда в сценарии A привязал №999: снова **«Создать док. перевозки»**.
17. Выбери **«Заявка к договору на перевозку грузов»** → **Создать**.
18. Заявка создаётся (номер **1** или следующий), ячейка показывает и договор, и **«Заявка № …»**.
19. Откроется редактор документов (вкладка договор) — бланк А4 заявки ещё этап 3, сейчас важен сам переход.

#### Сценарий D — нет перевозчиков (опционально)

20. Если временно убрать перевозчика из ЛК → **Профиль → Перевозчики → удалить** тестового,  
    то при создании «Договор на перевозку» увидишь:  
    **«Добавьте организацию в раздел Перевозчики…»**.  
    Потом верни seed: снова `ensure_schet_test_users.py`.

#### «Найти транспорт»

21. В той же ячейке нажми **«Найти транспорт»** → переход на  
    **http://localhost:3014/transport-search?deal=&lt;id&gt;** (поиск ТС уже из ТЗ_Перевозчик).
