## Как реализовывать

1. Открыть **[blanks/01-dogovor-perevozki.md](blanks/01-dogovor-perevozki.md)** — это поля, цвета и источники. Не гадать по docx.
2. Ключи полей — `blanks/schema.py` → `carriage_contract`.
3. В коде клонировать договор поставки (преамбула, шаблон, «Заполнить данными», фото/сканы, DOC/PDF). Красный шрифт ТЗ = что переименовать, не «поле locked».
4. Жёлтое — можно править на бланке после автозаполнения. Номер — жёлтый (сгенерили, пользователь может поправить).
5. Образец ТЗ (макет редактора): `dev/+ТЗ_Договор на перевозку грузов 22.08.2026/2_Страница_Договор перевозки.docx`. Пример текста договора (не ТЗ): `Документы/Пример_Договор перевозки грузов.doc`.

## §2.1. Макет и преамбула ✅

Шапка, город, дата, две формулы (юрлицо / ИП) по `company.type`. Остальные сочетания не программировать — жёлтые поля правят сами.

**Что сделано:** `CarriageContract.vue` на вкладке `#contract` (tab `5`), payload в `transport_document.payload_json`, PATCH API.

## §2.2. «Заполнить данными», шаблон, подписи ✅

Реквизиты и должностные лица из ЛК сторон. `ТЕКСТ ДОГОВОРА` — редактор шаблонов; «Таблица» и «СпецСим2» выключить.

**Что сделано:** `CarriageContractMenu` — «Заполнить данными», TipTap без таблицы/спецсимволов, галки реквизитов Заказчик/Перевозчик.

## §2.3. Фото/сканы + превью + DOC/PDF ✅

Тот же компонент, что на поставке / счёте. Подключить на этом типе.

**Что сделано:** `DealDocumentScans` с `document_type=contract`, печать превью; DOC/PDF серверного шаблона пока нет — через «Печать → Сохранить как PDF».

**Перенос на этап 3:** отображение скана в чате после «Отправить контрагенту» — см. [etap-03 §3.0](etap-03-zayavka.md).

## Как проверить

1. Dev-стек: `docker compose -f docker-compose.dev.yml up -d`
2. Seed:  
   `docker compose -f docker-compose.dev.yml exec backend poetry run python scripts/ensure_schet_test_users.py`
3. Войти: **http://localhost:3014/auth/login** — `seller@gmail.com` / `123456`
4. **Продажи** → ячейка «Договор перевозки» → создать «Договор на перевозку грузов» (или кликнуть уже созданный №999).
5. Откроется редактор, вкладка **Договор**, бланк А4.
6. **Редактировать** → жёлтые поля правятся; роли «Заказчик» / «Перевозчик».
7. Справа **Заполнить данными** — подтянутся реквизиты из ЛК и перевозчика.
8. **Редактор текста договора** — правит тело; галки реквизитов включают/выключают блок подписей.
9. **Отправить контрагенту и сохранить** — пишет `payload_json` на документ.
10. Режим просмотра → **Печать** (обычный браузер); блок **Фото/Сканы** — загрузка скана типа `contract`.
