### Как проверить — §3.1–§3.3 (по очереди)

**Учётка:** `seller@gmail.com` / `123456` · http://localhost:3014

#### §3.1
1. **Продажи** → колонка «Договор перевозки» → создать / открыть **Заявку к договору** (нужен родительский договор на заказе).
2. В редакторе вкладка **Договор**, в query `transportDocType=carriage_application`.
3. На А4 сверху красным: «Приложение к Договору … №999 от …» и «Заявка … №1» — **нельзя править** кликом.
4. Вторая заявка к тому же договору получает номер **2**.

#### §3.2
1. Привяжите перевозку к этой сделке (`/profile/shipments` → deal_id).
2. **Редактировать** → **Заполнить данными** / **Обновить таблицу перевозки** — серая таблица заполняется из груза/ТС.
3. **Редактор доп. условий** — текст меняется в сером блоке (на А4 блок не кликабелен).
4. **Редактировать данные перевозки** → ЛК Перевозки → вернуться → **Обновить таблицу**.

#### §3.3
1. **Заполнить данными** — жёлтые реквизиты/ФИО из ЛК.
2. Галочки «Реквизиты Заказчика / Перевозчика».
3. **Фото/Сканы** — загрузка / отправка контрагенту (тип `carriage_application`).
4. **Печать** — превью бланка заявки; DOC/PDF — предупреждение использовать печать→PDF.
