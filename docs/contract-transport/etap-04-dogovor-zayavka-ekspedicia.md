## §4.1. Бланк договор-заявки ✅

Преамбула + серая таблица + шаблон + реквизиты Заказчик/Перевозчик + экспорт.

**Что сделано:** `CarriageOrder.vue` + `useCarriageOrderBlank` + `CarriageOrderMenu`; номер/дата красные readonly; город и преамбула жёлтые; `CargoTransportTable` из этапа 3; пункты 1–7 в `DEFAULT_CARRIAGE_ORDER_EXTRA_TERMS`; сканы `carriage_order`.

## §4.2. Бланк договора экспедиции ✅

Преамбула Клиент/Экспедитор, шаблон, реквизиты (на макете страницы 5 таблица банка есть сразу), фото/сканы, DOC/PDF.

**Что сделано:** `ExpeditionContract.vue` + `useExpeditionContractBlank` + `ExpeditionContractMenu`; стороны Клиент/Экспедитор; реквизиты с банком; сканы `expedition_contract`; в Продажах подпись «Договор транспортной экспедиции № …».

## §4.3. Шаблоны на оба типа ✅

Редактор шаблонов, СпецСим1 в «Редактировать данные документа». «Таблица» / «СпецСим2» выключить.

**Что сделано:** TipTap «Редактор доп. условий» (заказ) и «Редактор текста договора» (экспедиция); без кнопок Таблица/СпецСим2.

### Как проверить — §4.1–§4.3

**Учётка:** `seller@gmail.com` / `123456` · http://localhost:3014

#### §4.1 Договор-заявка
1. **Продажи** → колонка «Договор перевозки» → создать **Договор-заявка** (справа нет списка старых — только «Создать новый»).
2. Вкладка **Договор**, query `transportDocType=carriage_order`.
3. Красные номер `000001…` и дата; жёлтый город; серая таблица; доп. условия 1–7.
4. **Заполнить данными** / привязать перевозку → таблица из груза/ТС.
5. **Печать** / сканы.

#### §4.2 Договор экспедиции
1. Создать **Договор транспортной экспедиции** (можно выбрать из списка старых).
2. Query `transportDocType=expedition_contract`.
3. На бланке **Клиент / Экспедитор** (не Заказчик/Перевозчик).
4. **Заполнить данными** → реквизиты из ЛК.
5. В ячейке Продаж: «Договор транспортной экспедиции № … от …».

#### §4.3 Шаблоны
1. На договор-заявке: **Редактировать** → **Редактор доп. условий** → изменить текст → на бланке серый блок обновился.
2. На экспедиции: **Редактор текста договора** → то же для тела.
