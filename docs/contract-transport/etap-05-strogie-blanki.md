# Этап 5 — Строгие бланки экспедиции

**Статус:** ⏳  
**Зависимости:** этап 4 §4.2 (на заказе есть договор экспедиции)

**Цель:** три формы Минтранса. Пользователь **не меняет вёрстку**. Все значения — диалог + «Заполнить данными».

| Экспедиторская расписка | [blanks/06-ekspeditorskaya-raspiska.md](blanks/06-ekspeditorskaya-raspiska.md) | `Документы/+Экспедиторская расписка.doc` |
| Складская расписка | [blanks/07-skladskaya-raspiska.md](blanks/07-skladskaya-raspiska.md) | `Документы/+Складская расписка.docx` |

Общее:

- Приложение к договору экспедиции: номер/дата родителя **красные**.
- Нумерация своя внутри договора (как заявки 1, 2, 3…).
- Без договора экспедиции на заказе сюда не пускает диалог этапа 1.
- Вес брутто/нетто: Σ (кол-во в заказе × вес из карточки товара), пустой вес = 0. Стоимость — сумма заказа.
- Пункт назначения (поручение п.11): адреса «места приёма груза» ЛК **покупателя**, первым — «по умолчанию» (ТЗ_15 этап 7).
- Грузоотправитель: контрагенты + поставщик.
- Клиент: выпадающий список из двух (поставщик / покупатель).
- Подпись на складской расписке — **экспедитор**, на остальных двух — **клиент**.

Не делать редактор шаблонов на этих трёх (бланк строгий).

---

## §5.1. Поручение экспедитору ⏳

Поля 1–22. Вид транспорта: авто / жд / море / воздух, дефолт автомобильный.

## §5.2. Экспедиторская расписка ⏳

Как поручение короче: нет грузополучателя, нет вида транспорта / пункта назначения / страховки в том же наборе — см. таблицу в md. Подпись клиента.

## §5.3. Складская расписка ⏳

По образцу, не по сводному ТЗ (там полей нет). Поле «Склад» — ручной ввод. Подпись экспедитора.

## §5.4. Экспорт трёх бланков ⏳

Превью, печать, DOC/PDF, фото/сканы — тот же компонент.
