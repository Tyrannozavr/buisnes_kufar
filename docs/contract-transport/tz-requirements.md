## A. Семь типов документов

Два семейства. Их нельзя смешивать в одном заказе без явного выбора пользователя.

### Семейство А — прямая перевозка (Заказчик ↔ Перевозчик)

| # | Документ | Роль | Нумерация | Родитель |
|---|----------|------|-----------|----------|
| 1 | **Договор перевозки грузов** | Рамочный договор, как договор поставки | своя | нет; привязка к организации из «Перевозчики» |
| 2 | **Заявка к договору** | Приложение к уже выбранному договору | **1, 2, 3…** внутри договора | договор перевозки на этом заказе |
| 3 | **Договор-заявка** | Разовая перевозка: договор + заявка в одном бланке | **000001** | нет списка старых договоров; только «Создать новый» |

### Семейство Б — экспедиция (Клиент ↔ Экспедитор)

| # | Документ | Роль | Нумерация | Родитель |
|---|----------|------|-----------|----------|
| 4 | **Договор транспортной экспедиции** | Рамочный, как договор поставки | своя | нет; привязка к организации из «Перевозчики» |
| 5 | **Поручение экспедитору** | Строгий бланк (приказ Минтранса) | очередной внутри договора | договор экспедиции на заказе |
| 6 | **Экспедиторская расписка** | Строгий бланк | очередной внутри договора | договор экспедиции на заказе |
| 7 | **Складская расписка** | Строгий бланк | очередной внутри договора | договор экспедиции на заказе |

Четыре роли при экспедиции:

1. **Поставщик** — продаёт товар.
2. **Покупатель** — покупает товар.
3. **Экспедитор** — организует перевозку; его нанимает поставщик или покупатель → для экспедитора это **Клиент**.
4. **Перевозчик** — кого нанимает экспедитор (если нет своего парка).

## B. Таблица «Продажи → Товары»

Колонки уже как в ТЗ_15:

`Заказ | Дата | Покупатель | Состояние | Счет | Договор поставки | Договор перевозки | Закрывающие документы`

### B.1. Ячейка «Договор перевозки»

Пример (заказ 00111):

- `Договор перевозки грузов № 999 от 08.04.25 г.`
- `Заявка № 1 от 08.04.25 г.`
- `Создать документ`
- `Заказ на перевозку № 00001 от 08.04.25 г.`
- `ООО «Перелетчик»`
- `Найти транспорт`

«Найти транспорт» — переход на уже существующую страницу поиска (ТЗ_Перевозчик). Здесь не переделывается.

Повторная сделка (заказ 00112, тот же покупатель и перевозчик):

- тот же **рамочный** договор № 999 выбирается заново;
- создаётся **новая заявка № 2** к этому договору;
- новый **заказ на перевозку № 00002**.

Паттерн как договор поставки + спецификация № 2.

### B.2. Диалог «Создать документ»

Радиокнопки (ровно 7):

1. Договор на перевозку грузов
2. Заявка к договору на перевозку грузов
3. Договор-заявка
4. Договор транспортной экспедиции
5. Поручение экспедитору
6. Экспедиторская расписка
7. Складская расписка

Кнопки: **Создать** / **Отмена**.

### B.3. Ветвления

#### Договор на перевозку грузов

1. Нет организаций в ЛК «Перевозчики» →  
   «Добавьте организацию в раздел Перевозчики для создания договора» → ОК → таблица.
2. Есть организации → диалог: **слева организации, справа договоры выбранной**.  
   Кнопки: **Отмена** (назад к выбору типа), **Выбор** (подставить договор в таблицу), **Создать новый** (редактор, вкладка «Договор» / «Договор на перевозку грузов»).  
   «Выбор» и «Создать новый» неактивны, пока не выбрана организация.

#### Заявка к договору

1. На заказе нет договора перевозки →  
   «В заказе нет выбранных Договоров на перевозку грузов» → ОК → назад к выбору типа.
2. Договор есть → редактор, подраздел «Заявка…», номер = следующий по этому договору.

#### Договор-заявка

Как договор перевозки по проверке «Перевозчики», но **справа списка договоров нет**.  
Кнопки только **Отмена** и **Создать новый** (неактивна без организации).

#### Договор транспортной экспедиции

Как договор перевозки: список организаций + список уже существующих договоров экспедиции + Выбор / Создать новый.  
Канон списка организаций: **«Перевозчики»** (не «Партнеры»).

#### Поручение / Экспедиторская расписка / Складская расписка

1. На заказе нет договора экспедиции →  
   «В заказе нет выбранных Договоров транспортной экспедиции» → ОК → назад к выбору типа.
2. Договор есть → редактор, соответствующий подраздел, очередной номер внутри договора.

Канон при «договор есть» для экспедиторской расписки: открыть **экспедиторскую расписку**, не заявку к договору перевозки.

## D. Бланк 1. Договор перевозки грузов

«Аналогичен договору поставки».

### Преамбула

**Оба юрлица:**

> ДОГОВОР ПЕРЕВОЗКИ ГРУЗОВ № ___  
> г. ГОРОД «___» _________ 20___ г.  
> ПОЛНОЕ НАЗВАНИЕ, далее — «Заказчик», от имени которого действует ДОЛЖНОСТЬ ФИО, действующего(ей) на основании ДОКУМЕНТ ОСНОВАНИЯ … с одной стороны,  
> и ПОЛНОЕ НАЗВАНИЕ, далее — «Перевозчик», … с другой стороны, … заключили настоящий Договор перевозки грузов…

**Заказчик — ИП** (поле «Тип организации»):

> … далее — «Заказчик», зарегистрированный в реестре индивидуальных предпринимателей под № ОГРН, с одной стороны, …

Остальные сочетания ТЗ намеренно опускает — правит пользователь.

Текст договора — шаблон. Подписи: Заказчик / Перевозчик, дата, М.П.  
Реквизиты: Заказчик слева, Перевозчик справа. Колонтитул — как у поставки.

## E. Бланк 2. Заявка к договору перевозки

Образец: `Документы/+Заявка к Договору перевозки грузов.docx`.

### Шапка

- «Приложение к Договору перевозки грузов № ___ от ___» — номер и дата уже выбранного на заказе договора.
- «Заявка на перевозку грузов № ___ от ___» — номер **от 1** в рамках этого договора.
- Строка сторон: ОПФ, название, ИНН, КПП, индекс, юр. адрес — **Заказчик** и **Перевозчик**.

### Таблица условий (автозаполнение)

Из **«Данные о грузе» + «Данные транспорта»** заказа на перевозку.

| Поле | Поле |
|------|------|
| Дата загрузки | Дата разгрузки |
| Время загрузки | Время выгрузки |
| Адрес загрузки | Адрес выгрузки |
| Маршрут | |
| Контакт на загрузке | Контакт на разгрузке |
| Наименование груза | |
| Условия перевозки | Тоннаж, тн · кол-во мест · объём |
| Ставка за перевозку, условия оплаты | |
| Водитель | паспорт РФ · телефон |
| ТС | марка тягача · гос. номер · номер п/п |

### Остальное

- **Дополнительные условия** — текст выбранного шаблона.
- Реквизиты сторон + подписи должностных лиц.
- В редакторе шаблонов выключить «Таблица» и «СпецСим2».
- «Редактировать данные перевозки» → диалог груза (ЛК «Перевозки»).
- Галочки реквизитов Заказчика / Перевозчика.

Не дублировать ручной ввод тех же полей, если груз уже заполнен в перевозке.

## F. Бланк 3. Договор-заявка (разовая перевозка)

Образец: `Документы/+Договор-заявка.docx`.  
Самостоятельный документ, не приложение к рамочному договору.

- Номер: маска **000000**, старт **000001**.
- Город — из ЛК Заказчика (поставщика), поле «Город».
- Преамбула — те же два варианта юрлицо / ИП, что у договора перевозки.
- Фиксированная фраза: перевозчик обязуется перевезти груз, заказчик — оплатить.
- Таблица условий — та же, что у заявки (груз + транспорт).
- Дополнительные условия — шаблон. В образце пункты 1–7 (исправное ТС, контроль погрузки, ТН/ТТН, акт выгрузки, дефекты, оплата не позднее дня после счёта, 2 экземпляра).
- Реквизиты + подписи.
- Шаблоны: «Таблица» и «СпецСим2» выключены.
- «Редактировать данные перевозки» → диалог груза.

## K. Канон по опечаткам исходника

1. «Создать экспедиторскую расписку» при наличии договора → открыть **расписку**, не заявку.
2. Договор экспедиции: организации из **«Перевозчики»**, не «Партнеры».
3. Автозаполнение: **груз + транспорт** перевозки, не второй ручной ввод тех же полей.
4. Реквизиты заявки на бланке: **Заказчик / Перевозчик** (не Поставщик/Покупатель).
5. Складская расписка: поля из образца.
6. Зеркало у перевозчика / экспедитора (просмотр бланка, фото/сканы, без редактирования) в исходнике почти не сказано. **Заложено в scope** по аналогии со счётом (read-only второй стороны). Если заказчик скажет «только создающая сторона» — вычеркнуть из пакета явно.
