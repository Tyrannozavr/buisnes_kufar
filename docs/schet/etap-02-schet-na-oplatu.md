## Scope

### 2.1. ОКЕИ (§A.1)

| Задача | Детали |
|--------|--------|
| Справочник | Коды ОКЕИ у единиц измерения в БД/API |
| UI | Автоподстановка кода в **заказе** и **счёте** по выбранной ед. изм. |

### 2.2. Страница подтверждения (§A.2)

| Задача | Детали |
|--------|--------|
| Checkout | Заказы по продавцам; товары и услуги — отдельные заказы |
| После «Подтвердить» | Запись в «Закупки» / «Продажи» |
| Уведомление | Сообщение продавцу в чате о новом заказе |

### 2.3. Таблицы «Товары» — Продажи / Закупки (§A.3)

| Задача | Детали |
|--------|--------|
| Колонки | Заказ, Дата, контрагент, Состояние, Счет, Договор поставки, Сопровод., Счёт-фактура, Другие |
| Нумерация | Маска **00000** + дата; ежегодный сброс |
| Сортировки | Заказ, Дата, контрагент (А–Я) |
| Действия | «Создать счет» → редактор / «Создать …» для прочих документов |
| Покупатель | «Просмотр» → read-only редактор (в т.ч. будущие сканы) |

### 2.4. Закладка «Заказ» — форма и команды (§B.1)

| Задача | Детали |
|--------|--------|
| Форма A4 | Организация, адрес, телефон, номер, дата, таблица, итоги, пропись |
| Должностные лица | Блок на форме заказа из ЛК |
| Команды | Предпросмотр, Печать, DOC, PDF, **Удалить данные**, Сохранить |
| Заполнить данными | На базе исправлений этапа 1 |

### 2.5. «Счет на оплату» — полное §5 (§E)

| Блок | Задачи |
|------|--------|
| Бланк | Вёрстка по приложению; жирные линии; «Основание» по галке |
| Итоги и НДС | Формула; скрытие/пустое поле без галки |
| Срок оплаты | *«Счет действителен в течении … рабочих дней…»* |
| Доп. информация | Текст §5.6 (дефолты — этап 1) |
| Подписи | 1–3 из ЛК при «Заполнить данными» |
| Сохранение | Все поля в API; reload |
| Общие команды счёта | Предпросмотр, печать, DOC, PDF, **Удалить данные**, Сохранить |
| DOCX/PDF | Шаблон = форма на экране |
| Формат чисел | `1,200.00`; пропись с копейками |

### 2.6. Фото/Сканы §4.3 — компонент + первые вкладки (§B.3)

| Задача | Детали |
|--------|--------|
| UI-блок | «Выберите файл», превью, Удалить, Сохранить локально |
| Вкладки | **Заказ**, **Счет на оплату** |
| Отправить контрагенту | Файл в чат + блок сканов у заявки |
| Покупатель | Read-only просмотр (референс — Elba в ТЗ) |
| API | Привязка к `deal_id` + тип вкладки; хранение файла |
