## Scope

| Блок | Задачи |
|------|--------|
| Бланк §5 | Вёрстка по приложению; жирные линии; «Основание» по галке |
| Итоги и НДС | Формула (согласовать «в т.ч.» / «сверху»); скрытие без галки |
| Срок оплаты | *«Счет действителен в течении … рабочих дней с момента выставления»* |
| Доп. информация | Текст §5.6 |
| Подписи | 1–3 из ЛК при «Заполнить данными» |
| Сохранение | Все поля в API; reload |
| DOCX/PDF | Шаблон `deal_docx_context` = форма |
| Экспорт UI | DOC/PDF/печать; **предварительный просмотр** |
| Формат чисел | `1,200.00`; прописью с копейками |
| **Фото/Сканы §4.3** | Блок «Фото/Сканы документа» на вкладках **Заказ** и **Счет на оплату**: «Выберите файл», превью, «Удалить», «Сохранить» (локально), «Отправить контрагенту»; покупатель видит сканы read-only (референс UX — Elba в ТЗ) |

**Не входит:** диалог «Создать счет», счёт-договор/оферта, договор поставки (этапы 3–4).

## Приёмка (20 000 ₽)

- [ ] Создать → заполнить → сохранить → DOC + PDF
- [ ] Все галки меняют бланк по §5
- [ ] Покупатель read-only
- [ ] Предпросмотр работает
- [ ] DOC/PDF = экран
- [ ] Фото/сканы: загрузка, превью, удаление, отправка контрагенту; покупатель видит на «Заказ» и «Счет»

**Срок:** 5–7 дней.
