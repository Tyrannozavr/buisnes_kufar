## Scope

### 3.1. Диалог «Создать счет» (§D)

| Задача | Детали |
|--------|--------|
| Нет договоров | «С данным контрагентом нет договоров. Создать без основания?» Да/Нет |
| Есть договоры | Список из ЛК «Договоры» + «Без договора» |
| Результат | Переход на «Счет»; маска **00000** + дата |
| Основание | Галка + текст `НОМЕР от ДАТА` на бланке и в меню |
| Таблица «Продажи» | Номер договора в колонке «Договор» при привязке |

### 3.2. API договоров

| Задача | Детали |
|--------|--------|
| Список | По контрагенту / из ЛК «Договоры» |
| Реализация | Свой API или merge `features/document-layer` — **в scope этапа**, не отдельная оплата |

### 3.3. Заказ — синхронизация и расширение (§B.2)

| Задача | Детали |
|--------|--------|
| Два документооборота | Разные номера заказа у сторон; одинаковое содержимое в сделке |
| Без автосинка | Изменение одной стороны не меняет заказ другой |
| Уведомление | При сохранении → «Контрагент изменил данные заказа» (чат) |
| Диалог | «Обновить данные?» при открытии до выравнивания |
| «Создать ДОКУМЕНТ на основании» | Переход на вкладку + автозаполнение из заказа |
| «Добавить продукт» | Выбор из прайса раздела «Продукция» ЛК |

### 3.4. Договор поставки (§F)

| Задача | Детали |
|--------|--------|
| Бланк | `SupplyContract/` по ТЗ; реквизиты из ЛК |
| Нумерация | **00000** + дата; ежегодный сброс |
| Команды | Заполнить данными, предпросмотр, печать, DOC, PDF, Удалить данные, Сохранить |
| Таблицы | Ссылки из «Товары»; «Создать договор» / «Просмотр» |
| Роли | Поставщик редактирует; покупатель — просмотр |

### 3.5. Фото/Сканы — договор поставки (§B.3, §F)

| Задача | Детали |
|--------|--------|
| Вкладка | **Договор поставки** |
| Сценарий ТЗ | Печать → подпись → скан → прикрепление → «Отправить контрагенту» |
| Чат | Уведомление контрагенту |
| Закупки | Скан виден покупателю в «Просмотр» (колонка «Счет» / блок файлов) |
| Хранение | Один файл на диске, ссылки у обеих сторон |
