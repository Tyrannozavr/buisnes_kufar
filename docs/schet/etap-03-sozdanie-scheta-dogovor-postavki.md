## Scope

| Блок | Задачи |
|------|--------|
| Диалог «Создать счет» | Нет договоров → «без основания?»; есть → список + «Без договора» |
| API договоров | Список по `buyer_company_id` или ЛК «Договоры» |
| Основание | Галка + `НОМЕР от ДАТА` на бланке и в меню |
| Таблица «Продажи» | Колонка «Договор» при привязке |
| Договор поставки | `SupplyContract/` vs бланк ТЗ; реквизиты из ЛК; «Заполнить данными» |
| Экспорт | DOC/PDF/печать договора поставки |
| **Фото/Сканы** | Блок на вкладке **Договор поставки**; сценарий из ТЗ: скан подписанного счёта → прикрепление → «Отправить контрагенту» → **уведомление в чате** + скан у покупателя в «Закупках» (колонка «Счет» / «Файлы») |
| API хранения | Привязка файла к `deal_id` + тип вкладки; один файл — одна копия на диске, ссылки у сторон (по ТЗ — на усмотрение, но в scope) |

**Не входит:** счёт-договор, счёт-оферта, редактор шаблонов (этап 4).
