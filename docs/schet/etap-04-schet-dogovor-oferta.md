## Scope

### 4.1. Переключение типов счёта (§C)

| Задача | Детали |
|--------|--------|
| `documentType` | Сохранение в payload; reload без потери |
| Смена типа | Предупреждение при переключении |
| Общие команды | Удалить данные, предпросмотр, печать, DOC, PDF — на всех типах |

### 4.2. Счет-договор (§G)

| Задача | Детали |
|--------|--------|
| Бланк | По приложению ТЗ |
| Условия | 9 пунктов; шаблоны; п.3 срок оплаты, п.4 срок поставки |
| Галки | Условия, срок оплаты, срок поставки, реквизиты поставщика/покупателя |
| Экспорт | DOC/PDF = экран |

### 4.3. Счет-оферта (§H)

| Задача | Детали |
|--------|--------|
| Бланк | Текст оферты под жирной чертой |
| Условия | 6 пунктов; **срок поставки — галка неактивна** |
| Доп. информация | Галка с текстом оферты по §7 |
| Экспорт | DOC/PDF = экран |

### 4.4. Редактор шаблонов условий (§I)

| Задача | Детали |
|--------|--------|
| Бэкенд | `contract_condition_templates`, CRUD, company-scoped |
| Seed | 2 шаблона: «Стандартный, доставка Поставщика/Покупателя» |
| UI | Модалка; список шаблонов; поле текста |
| По умолчанию | Пользователь может назначить шаблон default |
| Абзацы | Автонумерация при Enter |
| Спецсимволы | Кнопки «Срок оплаты» / «Срок поставки» в курсор |
| Связь | Текст шаблона ↔ активность галок сроков (§8.3) |

### 4.5. Фото/Сканы — счёт-договор и счёт-оферта

| Задача | Детали |
|--------|--------|
| Компонент | Переиспользование из этапа 2 |
| Вкладки | **Счет-договор**, **Счет-оферта** |
| Отправка | Чат + блок у контрагента; read-only у покупателя |

### 4.6. Таблицы «Услуги» — Продажи / Закупки (§A.4)

| Задача | Детали |
|--------|--------|
| Колонки | Заказ, Дата, контрагент, Состояние, Счет, Договор, Акт, Счёт-фактура, Другие |
| Нумерация | Маски **00000** + дата |
| Ссылки | «Создать счет/договор/акт/…» → редактор на нужной вкладке |
| Покупатель | «Просмотр» read-only |
