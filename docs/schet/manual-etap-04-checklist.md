## §4.1 — типы счёта ✅

Панель настроек документа — **справа** (не слева): селект **«Тип документа»** вверху правой колонки  
(`Счет на оплату` / `Счет-договор` / `Счет-оферта`). Слева — только превью бланка.

1. Открой http://localhost:8081/auth/login  
2. Войди: `seller@gmail.com` / `123456`  
3. **Профиль → Продажи → Товары**  
4. Колонка **«Счет»** → открыть сделку → вкладка **«Счет»** сверху  
5. Справа нажми **«Редактировать»** (если режим просмотра)  
6. В селекте справа смени тип (например с «Счет-договор» → «Счет на оплату») → появится модалка → **Продолжить**  
7. Сохрани («Отправить контрагенту и сохранить» или аналог)  
8. F5 — выбранный тип на месте  
9. Переключи на **«Счет-оферта»**, сохрани, F5 — снова тот же тип  
10. На каждом типе: DOC / PDF / печать  

Если при открытии уже стоит «Счет-договор» / оферта — так и должно быть (сохранённый `document_type`). Для проверки §4.1 **намеренно смени** тип в селекте справа.

После «Отправить контрагенту» у покупателя на вкладке **«Заказ»** — Принять/Отклонить. Подсветка позиций — только если менялись товары/сумма. Смена типа счёта показывается **текстом** в правой панели («Изменён тип счёта: … → …»), смотри также вкладку «Счет».

- [x] Типы сохраняются после reload  
- [x] Модалка только при ручной смене типа (не при простом открытии счёта)

## §4.2 — счёт-договор

1. Тип **«Счет-договор»**  
2. Галки: условия, срок оплаты, срок поставки, **реквизиты поставщика**, **реквизиты покупателя**  
3. На бланке блоки реквизитов появляются/скрываются  
4. **Редактор шаблона** → «Стандартный, доставка Поставщика» → сохранить  
5. Условия видны на бланке  
6. DOC и PDF ≈ экран

## §4.4 — шаблоны условий

1. Счёт-договор → **Редактор шаблона**  
2. В списке: «Стандартный, доставка Поставщика» / «…Покупателя»  
3. Кнопки **Срок оплаты** / **Срок поставки** вставляют плейсхолдеры  
4. Сохранить → текст на бланке обновился  
5. (Опционально) `buyer@gmail.com` — чужих шаблонов поставщика в редакторе нет

## §4.5 — сканы

1. `seller@gmail.com` → сделка → **Счет** → тип **«Счет-договор»**  
2. **Фото/Сканы** → Редактировать → загрузить файл → сохранить  
3. **Отправить контрагенту**  
4. `buyer@gmail.com` → Закупки → та же сделка → Счет: скан виден, без upload/delete  
5. Seller → тип **«Счет-оферта»** — сканы **отдельные** (`bill_offer`)

## §4.6 — «Услуги»
