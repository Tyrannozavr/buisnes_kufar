## §4.1 — типы счёта ✅

Панель настроек — **справа**. Слева только превью бланка.

1. Открой http://localhost/auth/login  
2. Войди: `seller@gmail.com` / `123456`  
3. **Профиль → Продажи → Товары**  
4. В колонке **«Счет»** открой любую сделку с счётом → сверху вкладка **«Счет»**  
5. Справа нажми **«Редактировать»** (если режим просмотра)  
6. Справа в селекте **«Тип документа»** смени тип (например «Счет-договор» → «Счет на оплату»)  
   - **Ожидание:** модалка «тип изменится» → **Продолжить**  
7. Нажми **«Отправить контрагенту и сохранить»** (или «Сохранить»)  
8. F5 — в селекте тот же тип, что сохранил  
9. То же для **«Счет-оферта»**  
10. На каждом типе жми зелёные **DOC / PDF / печать** — файл качается / печать открывается  

Модалка **не** должна появляться просто при открытии уже сохранённого счёта — только когда ты сам меняешь тип в селекте.

- [x] Типы сохраняются после F5  
- [x] Модалка только при ручной смене типа

## §4.2 — счёт-договор ✅

Цель: убедиться, что бланк **«Счет-договор»** живой — галки влияют на экран, условия из шаблона видны, DOC/PDF похожи на превью.

**Доп. приёмка (полировка):** дата счёта редактируется на бланке; в DOC нет `{{ … }}` / `None`; Корр/счет и Банк — разные строки; смена даты уходит контрагенту и подсвечивается жёлтым.

### Старт

1. Войди `seller@gmail.com`  
2. **Профиль → Продажи → Товары** → открой сделку (например заказ **00001**) → вкладка **«Счет»**  
3. Справа **«Редактировать»**  
4. Селект **«Тип документа»** → **«Счет-договор»** (если спросит — **Продолжить**)  

**Слева на превью** должно быть roughly: шапка банка, таблица товаров, блок **«Условия…»** с нумерованным текстом, внизу подписи / реквизиты сторон (если галки включены).

### Галки справа — что проверить

Справа есть чекбоксы (названия близко к этим). Для **каждой** галки сделай так: снять → смотреть бланк слева → снова поставить → смотреть бланк.

| Галка справа | Что должно произойти на бланке слева |
|--------------|--------------------------------------|
| **Условия договора** (или «Условия») | Блок с нумерованными условиями **пропадает**, когда галка снята; **появляется**, когда галка снова стоит |
| **Срок оплаты** | В условиях/тексте фигурирует срок оплаты (число дней). Если галка снята — срок из текста/блока уходит или не акцентируется (как в UI) |
| **Срок поставки** | Аналогично — срок поставки на бланке зависит от галки |
| **Реквизиты поставщика** | Блок **«ПОСТАВЩИК»** (ИНН, банк, адрес…) **скрывается** без галки и **возвращается** с галкой |
| **Реквизиты покупателя** | Блок **«ПОКУПАТЕЛЬ»** скрывается / появляется так же |

Если не находишь галку — смотри правую колонку целиком под селектом типа (иногда надо проскроллить).

### Шаблон условий

5. Справа найди кнопку/ссылку вроде **«Редактор шаблона»** / **«Редактировать условия»** → открой  
6. В списке шаблонов выбери **«Стандартный, доставка Поставщика»**  
7. При необходимости чуть измени текст (добавь слово в конец) → **Сохранить**  
8. Закрой редактор и посмотри **слева на бланк**  

**Ожидание:** на превью в блоке условий виден текст из шаблона (те же пункты / твоя правка).

### DOC и PDF

9. Зелёная кнопка **DOC** → скачай → открой в Word/LibreOffice  
   - Есть таблица товаров (не просто список «1. Болт — 100 × …» без таблицы)  
   - Есть условия из бланка  
   - Есть блоки/реквизиты, как на экране (если галки включены)  
   - Есть место подписи внизу  
10. То же для **PDF** — содержание совпадает с экраном (не обязательно пиксель-в-пиксель, но те же блоки)

- [x] Галки реквизитов/условий реально прячут и показывают блоки на бланке  
- [x] Шаблон «Стандартный, доставка Поставщика» попадает на бланк после сохранения  
- [x] DOC и PDF похожи на превью (таблица + условия + подпись/реквизиты)

## §4.3 — счёт-оферта ✅

Цель: отдельный тип бланка, у оферты срок поставки нельзя включать руками.

1. Ты всё ещё на вкладке **«Счет»**, режим редактирования  
2. Селект типа → **«Счет-оферта»** → модалка → **Продолжить**  

**Ожидание слева:** заголовок вроде **«Счет-оферта № …»**, условия оферты, товары.

3. Справа найди галку **«Срок поставки»**  
   - **Ожидание:** галка **видна**, но **серая / не кликается** (disabled). Кликом состояние не меняется.  
4. Справа галка **«Дополнительная информация»** — включи, если выключена.  
   Текст вводишь **слева на бланке**: сразу под таблицей товаров / итогами появится поле (textarea) «Дополнительная информация (оферта)» — правь там.  
   При включении галки может подставиться шаблонный текст — его можно заменить своим.
5. **Сохранить** → F5 → тип всё ещё «Счет-оферта»  
6. Скачай **DOC** и **PDF** оферты — заголовок оферты, товары, условия/доп.инфо как на экране  

- [x] Тип «Счет-оферта» сохраняется  
- [x] «Срок поставки» disabled  
- [x] DOC/PDF оферты ок

## §4.4 — редактор шаблонов условий ✅

Цель: шаблоны живут в API компании поставщика, плейсхолдеры сроков вставляются кнопками.

**Доп. приёмка (UX):** один селект шаблона; поле имени только для «Свой шаблон»; повторное сохранение с тем же именем — PATCH, не 409; покупатель бланк счёта не редактирует (только просмотр / accept-reject).

1. `seller@gmail.com` → сделка → **Счет** → тип **«Счет-договор»** → **Редактировать**  
2. Открой **редактор шаблона**  
3. В выпадающем списке должны быть хотя бы:  
   - «Стандартный, доставка Поставщика»  
   - «Стандартный, доставка Покупателя»  
4. Выбери один → в тексте нажми кнопки **«Срок оплаты»** и/или **«Срок поставки»**  
   - **Ожидание:** в текст вставились плейсхолдеры (кусочки вроде срока / спецмаркеры — как в UI)  
5. **Сохранить** → на бланке слева условия обновились  
6. (Опционально) Выйди, зайди как `buyer@gmail.com`, открой ту же сделку → **Счет**.  
   - У покупателя **нет** редактора шаблонов поставщика; поля бланка счёта **read-only**.  

- [x] Seed-шаблоны видны у seller  
- [x] Кнопки сроков вставляют плейсхолдеры, сохранение обновляет бланк  
- [x] Buyer чужие шаблоны не редактирует; счёт — просмотр

## §4.5 — фото / сканы ✅

Цель: у **счёт-договора** и **счёт-оферты** свои наборы сканов; покупатель только смотрит; после отправки есть уведомление.

**Доп. приёмка (dev):** бакет MinIO `documents` создаётся автоматически; предпросмотр сканов — jpeg/png/webp/**avif**/pdf; модалка «Обновить данные» убрана (версия уже в бланке + Принять/Отклонить).

1. Войди `seller@gmail.com` → сделка → **Счет** → тип **«Счет-договор»** → **Редактировать**  
2. Внизу справа блок **«Фото/Сканы документа»** → **Выберите файл** → загрузи любой мелкий PDF/JPG  
3. Нажми **«Отправить контрагенту и сохранить»**  
4. Выйди, войди `buyer@gmail.com` → **Профиль → Закупки → Товары** → та же сделка → вкладка **«Счет»**  
   - **Ожидание:** скан **виден** (скачать/открыть можно)  
   - Кнопок «загрузить» / «удалить» **нет** (или они не работают)  
5. (Опционально) Загляни в **чат** с этим контрагентом — должно быть сообщение про документ/счёт  
6. Снова seller → тип **«Счет-оферта»** → блок сканов  
   - **Ожидание:** набор файлов **другой** (скан с договора сюда сам не переехал). Загрузи второй файл только на оферту — у договора старый набор на месте.  

- [x] Загрузка скана на счёт-договор работает  
- [x] Buyer видит скан, не может грузить/удалять  
- [x] У оферты отдельный набор сканов

## §4.6 — таблицы «Услуги»

Цель: в Продажах/Закупках есть вкладка/фильтр **Услуги** со своими колонками; тестовый заказ **00004** без счёта.

1. Войди `seller@gmail.com`  
2. **Профиль → Продажи** → переключись на **«Услуги»** (вкладка рядом с «Товары», не таблица товаров)  
3. Найди заказ **00004**  
   - **Ожидание:** счёта ещё нет (ссылка «Создать счет» / пусто в колонке Счет)  
4. Посмотри колонки таблицы — должны быть примерно: Заказ, Дата, контрагент, Состояние, **Счет**, **Договор**, **Акт**, **Счёт-фактура**, **Другие**  
   - Колонки **«Договор поставки»** как у товаров здесь **нет** (это именно услуги)  
5. Жми **«Создать счет»** / «Счет» → открывается редактор, вкладка счёта (`#bill` или бланк счёта)  
6. Если в таблице есть ссылки **Договор** / **Акт** — жми: уходят в разделы `#contract` / `#act` (даже если бланк-заглушка)  
7. Выйди, войди `buyer@gmail.com` → **Закупки → Услуги**  
   - **Ожидание:** заказ виден, доступен **«Просмотр»**, без кнопок создания/правки счёта как у продавца

- [ ] Колонки Акт / Счёт-фактура / Другие на месте  
- [ ] Buyer — только просмотр
