## Куда зайти и что проверить — §2.2 Checkout

### Подготовка (один раз)

```bash
docker compose -f docker-compose.dev.yml exec backend poetry run python scripts/ensure_schet_test_users.py
```

В каталоге поставщика появятся:
- товар: `test-checkout-bolt-m8` — «Болт М8 (checkout)»
- услуга: `test-checkout-montazh` — «Монтаж оборудования (checkout)»

### Сценарий (покупатель)

1. Войти: http://localhost:8080/auth/login → **`buyer@gmail.com`** / `123456`
2. Добавить в корзину (кнопка на карточке):
   - http://localhost:8080/catalog/items/test-checkout-bolt-m8
   - http://localhost:8080/catalog/items/test-checkout-montazh
3. **Корзина** → **Оформить заказ** → `/checkout`
4. На странице **два блока** у «ООО Поставщик Тест»:
   - «Заказ на поставку **товаров**…»
   - «Заказ на оказание **услуг**…»
5. В каждом блоке нажать **«Подтвердить»**
6. **Профиль → Закупки** — два новых заказа (товары и услуги отдельно)

### Сценарий (поставщик)

1. Войти: **`seller@gmail.com`** / `123456`
2. **Профиль → Продажи** — те же два новых заказа
3. **Чаты** — сообщение от покупателя о новом заказе со ссылкой на редактор

### Что считается успехом

- [ ] Checkout показывает товары и услуги **отдельными** заказами
- [ ] Кнопка «Подтвердить» создаёт записи в Закупках и Продажах
- [ ] Продавцу приходит уведомление в чат

## Куда зайти и что проверить — §2.3 Таблицы «Товары»

### Покупатель (`buyer@gmail.com`)

1. **Профиль → Закупки** → вкладка **«Товары»**
2. После checkout (§2.2) — строки с товарными заказами (услуги на этой вкладке **не** видны)
3. Колонки: Заказ, Дата, Поставщик, Состояние, Счет, Договор поставки, Сопроводительные, Счет-фактура, Другие
4. Все ячейки — **«Просмотр»** → редактор read-only (`role=buyer`)

### Поставщик (`seller@gmail.com`)

1. **Профиль → Продажи** → вкладка **«Товары»**
2. «**Создать счет**» → редактор `#bill`, бланк только номер+дата
3. «**Создать договор поставки**» / «**Создать документ**» / «**Создать счет-фактуру**» → соответствующие вкладки
4. Сортировка: клик по заголовкам **Заказ**, **Дата**, **Покупатель**

### Успех §2.3

- [ ] 9 колонок по ТЗ на «Товары»
- [ ] Услуги не попадают на вкладку «Товары»
- [ ] Покупатель не редактирует документы из таблицы
