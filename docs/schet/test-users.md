1. **Профиль → Закупки** → вкладка **«Товары»**
2. После checkout (§2.2) — строки с товарными заказами (услуги на этой вкладке **не** видны)

## Куда зайти и что проверить — §2.5 Счёт на оплату

### Поставщик (`seller@gmail.com`)

1. **Профиль → Продажи** → «Создать счет» или открыть существующий счёт → вкладка **«Счёт»**
2. **Редактировать** → **Заполнить данными** — одна строка поставщик/покупатель (без «ООО ООО»)
3. Галка **«Основание»**, срок оплаты (рабочие дни), **«В том числе НДС»** (без галки — пустая строка)
4. **Доп. информация** — текст §5.6, **Сохранить**, F5 — данные на месте
5. **Удалить данные** — номер/дата счёта остаются
6. DOC / PDF — скачиваются

### Покупатель (`buyer@gmail.com`)

1. **Закупки** → **Просмотр** счёта — read-only, без «Редактировать» / «Сохранить»

## Куда зайти и что проверить — §2.6 Фото/Сканы

> Нужен MinIO/S3 в dev (`docker compose -f docker-compose.dev.yml`).

### Поставщик

1. Редактор → вкладка **«Заказ»** или **«Счёт»** → блок **«Фото/Сканы документа»**
2. **Редактировать** → **Выберите файл** (jpg/png/pdf)
3. **Сохранить локально** — скан в списке; **Просмотр** / **Сохранить локально** (скачать)
4. **Отправить контрагенту** — сообщение в чат со ссылкой на редактор
5. **Удалить** — скан пропадает из списка

### Покупатель

1. Тот же заказ → **Просмотр** — список сканов, просмотр и скачивание; без загрузки и удаления
