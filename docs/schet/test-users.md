## Куда зайти и что проверить (этап 1.1)

### 1. Вход

1. http://localhost:8080/auth/login  
2. `dmitiry40647274@gmail.com` / `123456`

### 2. ЛК «Данные компании»

**Профиль → Данные компании** (`/profile`)

- **Платежные реквизиты:** БИК, счета, банк, ставка НДС (проверить отсутствие 20% — баг этапа 1)
- **Информация о компании:** индекс `101000`
- **Должностные лица:** Тестов Дмитрий Сергеевич

### 3. Сделка и счёт

1. **Профиль → Продажи** (`/profile/sales/sales`)
2. Найти строку с покупателем **ООО Покупатель Тест**
3. В колонке **«Счет»** нажать **«Создать счет»**
4. Откроется редактор: `/profile/editor?dealId=…&role=seller#bill`
5. Вкладка **«Счет»** станет активной после создания счёта

### 4. Что смотреть на вкладке «Счет»

- Верхняя таблица реквизитов — должны быть данные **поставщика** (seller), не покупателя
- Блок «Поставщик» — индекс и адрес из ЛК
- Меню слева: ставка НДС, «Заполнить данными», подписанты

### 5. Контрагент (опционально)

Вход `seller@gmail.com` / `123456` → **Закупки** — та же сделка с другой стороны (read-only на счёте).
