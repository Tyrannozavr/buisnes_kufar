Seed: сделки товаров `00001`–`00003`, **услуга без счёта** `00004`; у поставщика **4 шаблона** условий (2 договор + 2 оферта).

### §4.1 — тип документа ✅

1. Войти поставщиком → **Продажи → Товары** → открыть сделку → вкладка **«Счет»**.
2. Селект типа — **справа** (не слева; слева превью бланка). При необходимости «Редактировать».
3. Сменить тип в селекте → подтвердить модалку → **Сохранить** → F5 → тип на месте.
4. То же для «Счет-оферта». DOC / PDF / печать на каждом типе.
5. Модалка **не** должна всплывать при простом открытии уже сохранённого счёта.

### §4.2 — счёт-договор ✅

1. Тип «Счет-договор».
2. Галки: условия договора, срок оплаты, срок поставки, **реквизиты поставщика/покупателя** — блоки на бланке скрываются/показываются.
3. «Редактор шаблона» — список из API (seed), сохранить текст → на бланке видны пункты.
4. Скачать DOC/PDF — условия и реквизиты соответствуют экрану; **нет** `{{ … }}` / `None`; Корр/счет и Банк на разных строках.
5. Дата в заголовке счёта редактируется → сохранить → у контрагента дата **жёлтым** + текст в меню «Изменена дата счёта».

### §4.3 — счёт-оферта ✅

1. Тип «Счет-оферта».
2. Галка **«Срок поставки»** видна и **неактивна**.
3. «Дополнительная информация» — галка справа; текст правится **слева на бланке** (textarea).
4. DOC/PDF оферты: подпись как на экране (только место акцепта, без лишнего блока officials).

### §4.4 — шаблоны ✅

1. В редакторе шаблона: выбрать «Стандартный, доставка Поставщика» / «Покупателя», править текст, **Сохранить**.
2. Кнопки «Срок оплаты» / «Срок поставки» вставляют плейсхолдеры; галки сроков синхронизируются с наличием плейсхолдеров.
3. Один селект; имя — только для «Свой шаблон»; повтор имени → обновление, не 409.
4. Покупатель шаблоны поставщика не редактирует; бланк счёта — **read-only**.

### §4.5 — сканы

1. Тип «Счет-договор» → блок **Фото/Сканы** → загрузить файл → **Отправить контрагенту**.
2. `buyer@gmail.com` → Закупки → та же сделка → вкладка «Счет»: скан виден, upload/delete нет.
3. Переключить на «Счет-оферта» — отдельный набор сканов (`bill_offer`).

### §4.6 — «Услуги»

1. `seller@gmail.com` → **Продажи → Услуги** → заказ **00004** (без счёта).
2. Колонки: Счет, Договор, **Акт**, Счёт-фактура, Другие (без «Договор поставки»).
3. «Создать счет» / «Просмотр» → редактор `#bill`; ссылки «Договор»/`Акт` → `#contract` / `#act`.
