### Быстрый вход

| Роль | URL редактора |
|------|----------------|
| Поставщик | http://localhost:3012/profile/editor?dealId=5&role=seller#order |
| Покупатель | http://localhost:3012/profile/editor?dealId=5&role=buyer#order |

Альтернатива: **Продажи** / **Закупки** → вкладка «Товары» → сделка «Этап 2 — тест ОКЕИ» → **Просмотр** / открыть заказ.

Логин: `seller@gmail.com` / `buyer@gmail.com`, пароль `123456`.

### Сценарий — поставщик (`seller@gmail.com`)

1. Редактор → вкладка **«Заказ»** → справа блок **«Фото/Сканы документа»**.
2. **Редактировать** → кнопка **«Выберите файл»** активна (jpg/png/pdf).
3. Выбрать файл → превью (для картинки) → **«Сохранить локально»** → toast «Скан сохранён», файл в списке.
4. У сохранённого скана: **Просмотр** (модалка), **Сохранить локально** (скачивание).
5. **Отправить контрагенту** (у файла в списке или сразу после выбора) → toast, в **Сообщения** у покупателя — текст со ссылкой на редактор.
6. **Удалить** — скан исчезает из списка.
7. Вкладка **«Счёт»** — те же шаги; сканы заказа и счёта **раздельные** (на «Заказ» не виден pdf счёта и наоборот).
8. F5 — сохранённые сканы на месте.

### Сценарий — покупатель (`buyer@gmail.com`)

1. **Закупки** → **Просмотр** той же сделки (или URL выше с `role=buyer`).
2. Блок **«Фото/Сканы документа»**: список сканов, **Просмотр** и **Сохранить локально**.
3. Нет: **Редактировать**, **Выберите файл**, **Удалить**, **Отправить контрагенту**.
