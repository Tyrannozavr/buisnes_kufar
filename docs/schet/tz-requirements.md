# Требования расширенного ТЗ (разделы 1–9)

Источник: `dev/WinRAR ZIP archive/Заявка Счет/ТЗ_Расширение.docx`  
Текстовая копия: `dev/WinRAR ZIP archive/Заявка Счет/ТЗ_Расширение.txt`

**Scope:** детально — закладка «Счет» (три типа). Договор поставки — базовое ТЗ (номер 00000, дата, бланк, сохранение, экспорт).

**Роли:** инициатор — **поставщик**; покупатель — просмотр бланка или сканов без редактирования.

---

## 1. Контекст

- Маска номера счёта **00000**, ежегодное обнуление, дата в колонке «Счет».
- «Создать счет» → редактор, вкладка «Счет».
- Бланки: `dev/WinRAR ZIP archive/Заявка Счет/Счет на оплату`, `Счет-договор+`, `Счет-оферта+`.

## 2. ЛК «Данные компании»

- **Платежные реквизиты:** БИК, корр. счёт, банк, расч. счёт, ставка НДС (5, 7, 10, 18, 20, 25, Без НДС).
- **Индекс** в информации о компании.
- **Должностные лица** — до 3 подписантов на счёте.
- **Формат чисел:** `1,200.00` руб.; сумма прописью с копейками.

## 3. Сценарий «Создать счет»

- Нет договоров → диалог «Создать без основания?»
- Есть договоры → выбор из ЛК «Договоры» или «Без договора»
- Основание: галка + текст `НОМЕР от ДАТА` на бланке

→ Реализация: [etap-03](etap-03-sozdanie-scheta-dogovor-postavki.md)

## 4. Закладка «Счет» (общее)

- А4, тип документа (3 вида), общие команды: Заполнить данными, просмотр, печать, DOC, PDF, удалить, сохранить, фото/сканы.

## 5. Счет на оплату

Реквизиты seller, заголовок, стороны, основание по галке, таблица товаров, итоги/НДС, срок оплаты, доп. информация (вкл. по умолчанию), подписи 1–3.

→ Реализация: [etap-01](etap-01-dorabotki-sergeya.md) (база) + [etap-02](etap-02-schet-na-oplatu.md) (полное §5)

## 6. Счет-договор

Бланк + условия договора (9 пунктов), шаблоны, сроки в п.3/п.4, реквизиты сторон.

## 7. Счет-оферта

Бланк оферты, 6 пунктов условий, срок поставки отключён.

## 8. Редактор шаблонов условий

Модалка, CRUD на бэкенде (company-scoped), спецсимволы сроков, двусторонняя связь с галками.

→ Реализация §6–8: [etap-04](etap-04-schet-dogovor-oferta.md)

## 9. Договор поставки

Базовое ТЗ + печать/DOC/PDF. Доводка — [etap-03](etap-03-sozdanie-scheta-dogovor-postavki.md).
