## Scope (кратко)

### 7.1. Вкладки данных компании
- «Данные компании» | «Данные заполнения» (тот же visual language).

### 7.2. Адреса погрузки / приёма
- CRUD списков; один default; если адрес один — он default.
- API company-scoped; миграции.

### 7.3. Карточка товара
- Убрать радио Товар/Услуга; всё → каталог товаров (проверить влияние на «Услуги» сделок пакета счёта — не сломать deals `Услуги` без явного решения; либо оставить тип на бэке скрытым).
- Поля вес нетто / вес брутто (optional).

### 7.4. «Заполнить данными» без проверок
- Убрать валидацию «поля должны быть заполнены» на заказе, счёте, договоре поставки и остальных редакторах.
- Регресс: заполнение всё ещё подставляет данные; пустые поля допустимы.

## Приёмка
- [ ] Две вкладки + адреса + default
- [ ] Вес в карточке товара
- [ ] «Заполнить данными» не блокирует при пустых реквизитах
