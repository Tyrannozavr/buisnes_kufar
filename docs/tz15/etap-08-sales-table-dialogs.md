**Самый рискованный этап** — пересекается с текущими колонками счёта.

## Scope (кратко)

### 8.1. Колонки таблицы «Товары» (Продажи / Закупки)
Новый набор:

`Заказ | Дата | контрагент | Состояние | Счет | Договор поставки | Договор перевозки | Закрывающие документы`

- Решение по старым колонкам (Сопровод. / СФ / Другие): **заменить** на закладке «Товары» по ТЗ_15; закладку «Услуги» пакета счёта оставить или согласовать отдельно.

### 8.2. «Создать документ» везде
- Даже если документ уже есть — ссылка создания остаётся.

### 8.3. Диалог замены счёта
- Есть счёт → «У данного заказа уже создан Счет…» Отмена / Создать (удалить старый, новый бланк).

### 8.4. Диалог Договор поставки / Спецификация
- Радио: договор поставки | спецификация.
- Ветки «нет договоров / есть / нет договора на заказе» — по тексту ТЗ_15.
- Опереться на уже существующие модалки спеки в `GoodsColumns.vue`, довести до ТЗ.

### 8.5. Договор перевозки + «Найти транспорт»
- MVP: «Найти транспорт» → stub/поиск этапа 5; диалог выбора/создания договора транспортной экспедиции (запись + ссылка в колонку).
- Полный бланк договора перевозки — stub в редакторе допустим.

### 8.6. Закрывающие документы
- Создание/ссылка (УПД-номер в таблице); бланк — stub.
