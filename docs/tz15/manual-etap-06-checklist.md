## §6.1 — Контрагенты

1. `seller@gmail.com` → **Профиль**
2. В меню **Бизнес-связи** пункт называется **«Контрагенты»** (не «Партнеры»)
3. Открой **Контрагенты** — в списке есть покупатели и перевозчик (ООО Перевозчик Тест)

- [x] В меню «Контрагенты», не «Партнеры»  
- [x] В списке покупатели + перевозчик вместе  

---



## §6.2 — Перевозчики и Перевозки

1. Seller → **Бизнес-связи → Перевозчики** — строка с ООО Перевозчик Тест
2. В меню есть блок **Перевозки** → **Перевозки**, **Заявки**, **Избранное** (пустые таблицы ок)
3. `carrier@gmail.com` → меню: Контрагенты, Перевозчики, Перевозки, Заявки; **Избранного нет**

- [x] Раздел «Перевозчики» в Бизнес-связях  
- [x] Seller: Перевозки+Заявки+Избранное; carrier: без Избранного  

---



## §6.3 — Добавить контрагента

1. Seller → открой публичную карточку перевозчика, напр. `/companies/test-carrier-tz15`
2. Одна кнопка **«Добавить контрагента»** → без диалога (логистика) — попадает в Контрагенты + Перевозчики
3. Открой карточку обычной компании-продавца → **Добавить контрагента** → диалог Поставщики/Покупатели

- [x] Одна кнопка + ветки  

---



## §6.4 — Посмотреть договоры

1. Seller → **Контрагенты** → у ООО Покупатель Тест нажми **«Посмотреть договоры»**
2. Открывается **Документы** с `?counterparty_id=` и блок договоров ЛК (00015 / 00027)

- [x] Ссылка и фильтр
