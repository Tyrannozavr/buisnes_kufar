## Блок 0. Публичное меню (гость)

1. Открой http://localhost:3014 (без логина или выйди из аккаунта).
2. В верхнем меню проверь пункты:
   - есть **Каталог товаров**, **Продавцы**, **Производители**, **Перевозчики**, **Поиск транспорта**, **О нас**, **Объявления**;
   - пункта **Новости** нет.
3. Нажми **Продавцы** — страница открывается без ошибки.
4. Нажми **Перевозчики** — страница открывается.
5. Нажми **Поиск транспорта** — открывается заглушка (не 404).

- [ ] Меню гостя ок  
- [ ] Поиск транспорта — заглушка без ошибки

## Блок 1. Поставщик (`seller@gmail.com`)

### 1.1 Вход и профиль

1. Открой http://localhost:3014/auth/login  
2. Введи `seller@gmail.com` / `123456` → **Продолжить**.  
3. В шапке должно быть **ООО Поставщик Тест**.  
4. Перейди в **Профиль** (или `/profile`).

- [ ] Вход seller ок  
- [ ] В шапке название компании  

### 1.2 Данные компании и торговая деятельность

1. На `/profile` открой вкладку **Данные компании**.  
2. Найди поле **Торговая деятельность** — должны быть: Производитель / Продавец / Перевозчик / Экспедитор.  
3. Убедись, что полей **«Род деятельности»** и **«Вид деятельности»** нет.  
4. (Опционально) смени значение → **Сохранить** → обнови страницу — значение осталось.

- [ ] 4 роли в «Торговая деятельность»  
- [ ] Род/вид деятельности убраны  

### 1.3 Данные заполнения (адреса)

1. На `/profile` открой вкладку **Данные заполнения**.  
2. Посмотри блоки адресов **погрузки** и **приёма** (после seed адреса уже есть).  
3. Добавь новый адрес приёма → сохрани.  
4. Проверь: у одного адреса kind стоит **По умолчанию**.  
5. Добавь второй адрес погрузки → назначь ему **По умолчанию** → у предыдущего того же kind галка снимается.  
6. Удали адрес «по умолчанию» (если остаётся другой) — default переназначается.

- [ ] Вкладки «Данные компании» / «Данные заполнения»  
- [ ] CRUD адресов работает  
- [ ] «По умолчанию» корректно  

### 1.4 Меню ЛК поставщика

В боковом меню профиля должны быть:

- **Данные компании**, **Продукция**, **Объявления**
- **Контрагенты**, **Перевозчики**, **Поставщики**, **Покупатели**
- **Документы**, **Договоры**, **Редактор документов**, **Закупки**, **Продажи**
- блок **Перевозки** (Перевозки / Заявки / Избранное)

- [ ] Меню seller полное (есть Продукция, Продажи, Закупки)  

### 1.5 Контрагенты

1. Меню → **Контрагенты** (или `/profile/partners`).  
2. Пункт называется **«Контрагенты»**, не «Партнеры».  
3. В списке есть **ООО Покупатель Тест** и **ООО Перевозчик Тест**.  
4. Открой вручную `/profile/counterparties` — должен открыться тот же раздел (редирект, не 404).  
5. У **ООО Покупатель Тест** нажми **Посмотреть договоры** → открываются **Документы** с фильтром по контрагенту; видны договоры (например 00015 / 00027).

- [ ] Список контрагентов ок  
- [ ] `/profile/counterparties` не 404  
- [ ] «Посмотреть договоры» ведёт в Документы  

### 1.6 Перевозчики и документы

1. Меню → **Перевозчики** — есть **ООО Перевозчик Тест**.  
2. Меню → **Документы** — таблица + фильтры: Контрагент / Тип / Период / Закупки·Продажи / Заказ.  
3. Смени фильтр контрагента — список обновляется.

- [ ] Раздел Перевозчики  
- [ ] Фильтры Документы  

### 1.7 Добавить контрагента (публичная карточка)

1. Открой `/companies/test-carrier-tz15`.  
2. Нажми **Добавить контрагента** (для перевозчика — без диалога ролей).  
3. Вернись в **Контрагенты** / **Перевозчики** — компания на месте (или уже была после seed).

- [ ] Кнопка «Добавить контрагента» работает  

### 1.8 Продукция — вес

1. Меню → **Продукция** (`/profile/products`).  
2. Создай или отредактируй товар.  
3. Проверь: **нет** переключателя Товар/Услуга.  
4. Заполни **Вес нетто** и **Вес брутто** → сохрани → открой снова — веса на месте.

- [ ] Нет радио Товар/Услуга  
- [ ] Веса сохраняются  

### 1.9 Продажи — таблица «Товары» (колонки ТЗ)

1. Меню → **Продажи** (`/profile/sales`).  
2. Вкладка **Товары**.  
3. Проверь колонки (слева направо):  
   **Заказ | Дата | Покупатель | Состояние | Счет | Договор поставки | Договор перевозки | Закрывающие документы**.  
4. В ячейках документов у seller есть **«Создать документ»** (даже если документ уже есть).  
5. В колонке перевозки есть **«Найти транспорт»**.

- [ ] 7 колонок документов по ТЗ  
- [ ] «Создать документ» видно  
- [ ] «Найти транспорт» видно  

### 1.10 Продажи — замена счёта

1. Найди сделку, у которой уже есть счёт (после seed — сделка 1).  
2. В колонке **Счет** нажми **Создать документ**.  
3. Должен появиться диалог **замены** счёта.  
4. Подтверди **Создать** → открывается редактор счёта (`#bill` / редактор документов).

- [ ] Диалог замены счёта  
- [ ] Переход в редактор  

### 1.11 Продажи — договор / спецификация

1. В колонке **Договор поставки** нажми **Создать документ**.  
2. Появляется выбор: **договор** / **спецификация** (radio).  
3. Выбери договор → создаётся / открывается документ.  
4. (Если есть сделка без договора) попробуй спецификацию — должно быть предупреждение по ТЗ.

- [ ] Radio договор / спецификация  
- [ ] Спека без договора — предупреждение (если сценарий доступен)  

### 1.12 Продажи — перевозка и закрывающие

1. Колонка **Договор перевозки** → **Найти транспорт** → открывается `/transport-search` (заглушка ок).  
2. **Создать документ** в перевозке → диалог выбора / «Создать новый» → переход в редактор (MVP-stub ок).  
3. Колонка **Закрывающие документы** → **Создать документ** → создаётся УПД-style запись → редактор.

- [ ] Найти транспорт  
- [ ] Создать договор перевозки (MVP)  
- [ ] Создать закрывающий документ (MVP)  

### 1.13 Продажи — «Услуги»

1. Вкладка **Услуги**.  
2. Колонки счёта (Договор / Акт / СФ / Другие) на месте, страница без ошибки.

- [ ] Вкладка Услуги не сломана  

### 1.14 Заполнить данными в редакторе

1. Продажи → открой сделку 1 → редактор заказа/счёта.  
2. Нажми **Заполнить данными** → **Продолжить**.  
3. Ожидание: toast успеха, бланк заполнен доступными данными; **нет** блокировки из‑за пустых реквизитов.

- [ ] «Заполнить данными» у seller работает без жёсткой валидации
