## A. Главное меню и каталоги → **этап 5**

- Переименовать **«Каталог услуг»** → **«Продавцы»** (путь/смысл раздела — каталог компаний-продавцов; не путать с «Продажи» в ЛК).
- Переименовать **«Услуги»** → **«Перевозчики»**.
- Убрать пункт **«Новости»** из главного меню (блок «Новые компании» / `/companies` остаются).
- После «Перевозчики», перед «О нас» — раздел **«Поиск транспорта»** (этап 5: страница-заглушка; полный поиск — вне 80k).

---

## B. Торговая деятельность и роли → **этап 5**

Значения выпадающего списка **«Торговая деятельность»**:

1. **Производитель** → меню «Производители».
2. **Продавец** → меню «Продавцы».
3. **Перевозчик** → меню «Перевозчики»; в ЛК **недоступны**: Продукция, Поставщики, Покупатели, Продажи, Закупки.
4. **Экспедитор** → меню «Перевозчики»; те же ограничения ЛК.

Удалить поле **«Род деятельности»** (+ список + комментарий).

Меню ЛК перевозчика/экспедитора (каркас этапа 5): Данные компании, Транспорт, Водители, Объявления, Контрагенты, Документы, Перевозки, Заявки, Избранное, Сообщения, Авторизация, Администрирование — пункты без данных = понятная заглушка.

## C. Контрагенты и перевозки → **этап 6**

- «Партнеры» → **«Контрагенты»** (общий список покупателей + поставщиков + перевозчиков).
- Новый раздел **«Перевозчики»** в «Бизнес-связи».
- Новый блок **«Перевозки»** (между «Документы и финансы» и «Коммуникации»):
  - у Перевозчика/Экспедитора: **Перевозки**, **Заявки**;
  - у Производителя/Продавца: **Перевозки**, **Заявки**, **Избранное**.
- Клиентская страница компании: одна кнопка **«Добавить контрагента»**:
  - Перевозчик/Экспедитор → Контрагенты + Перевозчики;
  - Продавец/Производитель → диалог: Поставщики и/или Покупатели + Контрагенты.
- Карточка в «Контрагенты»: Написать сообщение, **Посмотреть договоры**, Удалить.
- «Посмотреть договоры» → ЛК «Документы», фильтр по контрагенту.
- «Документы» — единая таблица документов организации с фильтрами.

## D. Данные компании и товар → **этап 7**

- Две закладки: **«Данные компании»** (как сейчас) и **«Данные заполнения»**.
- В «Данные заполнения»:
  - **Адрес места погрузки товара** — список, add, один «по умолчанию»;
  - **Адрес места приема груза** — то же.
- Карточка товара: убрать радио **Товар/Услуга**; всё в каталог товаров; поля **вес нетто**, **вес брутто** (необязательные).
- **«Заполнить данными»** в редакторе: **не** проверять заполненность полей (заказ, счёт, договор поставки и далее — везде).

## E. Таблица «Продажи» и диалоги → **этап 8**

Колонки (Товары):

`Заказ | Дата | Покупатель | Состояние | Счет | Договор поставки | Договор перевозки | Закрывающие документы`

- Ссылки **«Создать документ»** в колонках даже если документ уже есть.
- Колонка «Счет»: если счёт есть — диалог замены (Отмена / Создать).
- «Договор поставки»: диалог типа документа (Договор поставки / Спецификация) + ветвления по ТЗ.
- «Договор перевозки»: «Найти транспорт» + диалог выбора/создания договора транспортной экспедиции (MVP).
- «Закрывающие»: ссылка на создание/просмотр (УПД и т.п. — stub бланка допустим, навигация и создание записи — обязательны).

> Текущие колонки этапа счёта (Сопроводительные / СФ / Другие) **заменяются** моделью ТЗ_15 на закладке «Товары». Закладка «Услуги» из пакета счёта — не ломать без явного решения; в этапе 8 зафиксировать совместимость.
