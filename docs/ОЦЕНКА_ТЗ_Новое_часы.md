# Оценка трудозатрат: новое ТЗ (часы)

**Дата оценки:** 18.06.2026  
**Источник:** `ТЗ_Изменения.docx`  
**Методика:** оценка «с нуля», без учёта уже реализованного функционала  

## Условия

- 1 разработчик (middle+/senior), fullstack
- Backend + frontend + миграции + базовые тесты + интеграция
- Без PM, отдельного дизайна, нагрузочного тестирования
- Буфер на баги и стыковку заложен в диапазоны (±15–20%)
- Блок «Перевозки» в тексте ТЗ описан схематично — верхняя граница может вырасти на 20–30%
